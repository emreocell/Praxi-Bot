# Praxi documentation

Praxi is a self-hosted AI agent. It runs on your own computer, works for you, and
asks before it does anything that changes something. These pages explain how to use
it, how it stays safe, and how to help build it.

In another language: [Türkçe](guide/tr/index.md) · [Deutsch](guide/de/index.md).
Pages that are not translated yet open in English.

No technical knowledge needed. Short pages in plain words, in this order:

1. [Getting started in 5 minutes](guide/getting-started.md): install, first chat.
2. [Keep your bot safe](guide/keep-your-bot-safe.md): what it may do, and when it asks you.
3. [Fix common problems](guide/fix-common-problems.md): the most likely problems and what to do.
