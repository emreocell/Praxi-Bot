# Auf diesem Computer oder auf einem Server

**Kurze Antwort: Lass es auf diesem Computer laufen. Du brauchst keinen Server.**

## Auf diesem Computer (Standard)

Deine Bots laufen auf dem Computer, auf dem du Praxi installiert hast. Sie arbeiten, solange Praxi offen und dein Computer wach ist.

- Einfach: Du musst nichts weiter einrichten.
- Privat: Deine Chats und Dateien bleiben hier.
- Grenze: Wenn dein Computer aus ist oder schläft, arbeiten deine Bots nicht. Geplante Jobs warten auf dich (siehe [Dinge automatisieren](automate.md)).

In der App heißt dieser Computer **Dieser Computer**. Du siehst ihn im Computer-Menü oben.

## Auf einem Server (optional)

Ein **Server** ist ein weiterer Computer, der Tag und Nacht läuft. Die meisten mieten ihn online. Manche nutzen einen alten PC zu Hause.

Wähle einen Server nur, wenn:

- Jobs nachts laufen sollen, während dein eigener Computer aus ist, oder
- deine Bots dir zu jeder Stunde vom Handy aus antworten sollen.

Das solltest du vorher wissen:

- Ein Server kann Geld kosten. Manche Anbieter haben einen kostenlosen Tarif.
- Du brauchst ein paar einfache Angaben: die Adresse des Servers, einen Benutzernamen und eine Schlüsseldatei.
- Ein Bot auf einem Server arbeitet mit den Dateien des Servers, nicht mit deinen eigenen.
- Die Schlüssel und Chats dieses Bots liegen auf dem Server. Behandle ihn wie einen zweiten Computer, den du sicher halten musst.

## So fügst du einen Server hinzu

1. Öffne oben das Computer-Menü.
2. Wähle **Server hinzufügen …**.
3. Folge den drei kurzen Schritten. Praxi prüft den Server und sagt dir, was du beheben musst.

Die ganze Anleitung samt kostenloser Möglichkeit steht unter [Server hinzufügen](../servers.md). Befehle für einen Linux-Server stehen unter [Dauerhaft laufender Linux-Host](linux-host.md).

> **Bild:** das Computer-Menü mit **Dieser Computer** und **Server hinzufügen …**.

## Zurückwechseln oder einen Server entfernen

- Wähle im Computer-Menü **Dieser Computer**, um wieder lokal zu arbeiten.
- Öffne im Computer-Menü **Deine Server** und drücke **Entfernen**, um einen Server zu vergessen. Der Server selbst und seine Bots laufen weiter. Nur dieser Computer vergisst ihn.

## Wenn ein Server nicht antwortet

Die Meldung „{name} hat nicht geantwortet“ bedeutet, dass der Server aus ist oder kein Netzwerk hat. Schalte ihn ein und versuche es erneut. Weitere Schritte: [Häufige Probleme lösen](fix-common-problems.md).
