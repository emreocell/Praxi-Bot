# plugin-host

`plugin-host` is a reserved placeholder. It has no code yet: it does not load
plugin manifests, start plugin processes, or run WASM modules. The plugin system
design is tracked in [issue #213](https://github.com/emreocell/Praxi-Bot/issues/213).
`cargo test -p plugin-host` builds the crate, but the crate has no tests today.
