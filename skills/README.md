# Bundled Skills

Each directory under `skills/` contains a `SKILL.md` playbook embedded into the `skills` crate (see [docs/guide/skills.md](../docs/guide/skills.md) for the format).

- `cookie-consent-banners` — Dismiss cookie and consent banners choosing the most privacy-preserving option.
- `custom-dropdowns` — Operate non-native dropdowns, comboboxes and autocomplete lists built from divs.
- `date-pickers` — Enter dates in text inputs and calendar popups, including format and month navigation pitfalls.
- `github-basics` — Navigate github.com repositories, issues, pull requests and search efficiently.
- `install-capability` — Guide owners through approving and installing missing host tools; never bypasses limits.
- `lead-research` — Research potential customers and maintain a structured CSV lead list in the workspace.
- `linux-file-upload-dialog` — Operate native GTK and Qt file chooser dialogs on Linux after clicking a web upload button.
- `macos-file-dialogs` — Operate the native macOS Open and Save panels: Go to Folder, the replace prompt, hidden files and verifying the result.
- `office-doc-prep` — Create and inspect docx, xlsx, and csv office files with built-in tools.
- `outreach-drafts` — Draft personalized outreach emails per lead for owner review; never sends.
- `shadow-dom-and-iframes` — Reach elements hidden inside shadow DOM or iframes when browser_snapshot does not list them.
- `sign-in-forms` — Handle multi-step sign-in flows, SSO redirects, and 2FA prompts safely using stored fill secrets.
- `signup-to-site` — Sign up on a website using Vault secrets and human handover for CAPTCHA or 2FA.
- `web-tables-and-spreadsheets` — Navigate, read, and edit grid cells, paginated tables, and spreadsheet web apps reliably.
- `windows-file-upload-dialog` — Handle the native Windows "Open" file picker that appears after clicking an upload button.
- `windows-save-as-dialog` — Save to a requested path through the native Windows Save As dialog and handle overwrite prompts.
- `windows-settings-navigation` — Open and navigate the Windows Settings app via ms-settings URIs and its accessibility tree.
